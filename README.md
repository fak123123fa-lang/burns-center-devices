# نظام إدارة الأجهزة الطبية — المركز التخصصي للحروق (الديوانية)

الواجهة العامة للنظام:
- `index.html` — بطاقة الجهاز التي تفتح عند مسح ملصق QR (+ الإبلاغ عن عطل).
- `app.html` — البرنامج (لا يحتوي بيانات؛ البيانات تُحمَّل بعد تسجيل الدخول من الحفظ الأونلاين).

مؤسسة الفرقان البرمجية — رصانة، دقة، أمان
